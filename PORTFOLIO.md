# Описание для портфолио

**EventHub — платформа для поиска и организации IT-мероприятий.**

Я реализовал каталог с фильтрацией, динамические страницы событий, регистрацию через Reactive Forms, электронные билеты, персональное расписание, кабинет организатора и check-in. Параметр маршрута передаётся напрямую в signal input компонента, а все изменения проходят через типизированный store.

**Практическая направленность:** проект покрывает два пользовательских контура — участника и организатора. Он может стать MVP сервиса конференций после подключения платежей, email-уведомлений и backend API.

**Что демонстрирует:** Angular Router, route input binding, Signals, формы, сложная адаптивная верстка, CRUD, роли интерфейса, accessibility basics и тестирование бизнес-сценариев.
